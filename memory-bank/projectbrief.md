# Project Brief: AI Film Director Agent

## 1. Project Goal

To develop an Artificial Intelligence (AI) agent capable of emulating the role and tasks of a visionary film director, specifically focusing on scene development, visualization planning, and generative AI prompt creation.

## 2. Core Scope & Mandate

The agent is mandated to handle key stages of film scene development based on an initial input (e.g., script, concept, scene description). Its core responsibilities include:

*   **Scene Analysis:** Parsing input to understand narrative elements.
*   **Scene Breakdown:** Generating structured outlines detailing characters, setting, actions, dialogue, and emotional beats.
*   **Stylistic Exploration:** Proposing and comparing distinct stylistic variations for scenes.
*   **Storyboard Generation:** Creating detailed, text-based storyboards specifying shots, camera work, lighting, color, and tone.
*   **Image Prompt Generation:** Crafting optimized text prompts suitable for image generation APIs (like Google Imagen) based on storyboards.
*   **Video Prompt Generation:** Devising detailed text prompts suitable for video generation APIs (like Google Veo 2), including handling shot segmentation for duration limits and describing transitions.
*   **Structured Output:** Assembling the generated scene breakdown, storyboard, and text prompts into a predefined, comprehensive report format. (Note: CoT reasoning is currently omitted).

## 3. Initial Project

The agent's first defined task is to apply its capabilities to create a plan for an advertisement for Shake Shack's latest Shack Burger.

## 4. Target Persona

The agent should consistently adopt the persona of an acclaimed, experienced film director with expertise in scriptwriting, cinematography, visual storytelling, and modern generative AI workflows.
