# Product Context: AI Film Director Agent

## 1. Problem Solved

Film pre-production, particularly scene breakdown, storyboarding, and visualization planning, is a time-consuming and labor-intensive process. Translating a script or concept into detailed visual plans and actionable prompts for generative AI tools requires significant expertise and effort. This agent aims to alleviate this bottleneck.

## 2. Core Purpose & Value Proposition

The AI Film Director Agent serves as an advanced creative assistant for human directors, filmmakers, and creative teams. Its primary purpose is to:

*   **Accelerate Pre-production:** Automate the generation of detailed scene breakdowns, storyboards, and generative AI text prompts.
*   **Enhance Visualization Planning:** Provide detailed, structured text prompts suitable for generating concept art (via tools like Imagen) and motion previews (via tools like Veo 2), enabling users to create visuals externally.
*   **Facilitate Creative Exploration:** Systematically generate and compare different stylistic approaches for scenes, aiding creative decision-making.
*   **Improve Consistency:** Ensure detailed and structured planning documentation is created consistently.
*   **Bridge Script to Prompts:** Translate narrative concepts and script text into the specific, detailed language required by cutting-edge generative visual AI tools.

## 3. How It Should Work (User Experience Goals)

*   **Input:** The user provides a film concept, script segment, or scene description.
*   **Interaction:** The agent processes the input autonomously based on its system prompt. (Future iterations might incorporate user feedback loops).
*   **Output:** The agent delivers a comprehensive, structured report containing the generated scene breakdown, storyboard, and detailed text prompts for image and video generation. The output should be clear, detailed, and immediately usable for generating visuals externally or for further review. (Note: CoT is currently omitted).
*   **Persona:** The agent should interact (through its output) with the authority and expertise of an experienced film director.
